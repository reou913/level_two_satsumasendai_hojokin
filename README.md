# 薩摩川内市 補助金・助成金さがし

薩摩川内市・川内商工会議所のホームページと、国の補助金サイト「Jグランツ」から、補助金・助成金を集めて一覧にするWebアプリです。
GitHub Actions が毎週月曜の朝7時に自動で巡回し、一覧を新しくします。

## できること

| 機能 | 内容 |
| --- | --- |
| 検索・絞り込み | キーワード、だれ向け、分野、どこの制度（市・商工会議所・国や県） |
| 締切と金額 | 各ページから締切・上限額・補助率を読み取って表示。「あと○日」、締切2週間以内は赤 |
| 並び順 | おすすめ順・締切が近い順・新しく載った順 |
| かんたん診断 | 3つの質問に答えると、合う補助金にしぼり込む |
| お気に入り | ☆を押した補助金を、その端末に保存 |
| 条件の共有 | 絞り込んだ状態がURLに残る。「この条件を共有」でLINEなどに送れる |
| 印刷 | 絞り込んだ一覧を、URLつきで印刷できる |
| 新着 | 新しく載ったものに「新着」マーク。RSS（feed.xml）でも受け取れる |
| 最近の変更 | 「新しく載りました」「受付終了になりました」などを日付つきで表示 |
| セミナー・相談会 | 川内商工会議所の講演会・相談会のお知らせ |
| 異常の知らせ | 巡回先が読めない・件数が急に減ったときに、GitHub の Issue で知らせる |

## ファイルの構成

```
index.html                    一覧ページ
feed.xml                      新着のRSS（巡回のたびに作り直す）
data/subsidies.json           集めた補助金・セミナーの一覧（巡回のたびに書きかわる）
data/history.json             変更の記録（巡回のたびに書き足す）
sources.json                  巡回するページのリスト
scripts/crawl.py              巡回するスクリプト（Pythonの標準機能だけで動く）
.github/workflows/crawl.yml   毎週自動で巡回するための設定（GitHub Actions）
.gitignore                    GitHub に上げないファイルのリスト
```

## 前のバージョンから更新するとき

1. zip を解凍し、中身をすべてアップロードして上書きする（`data` フォルダは入っていないので、今のデータはそのまま残ります）
   - `.github` と `.gitignore` は名前が「.」で始まるため、Mac では見えないことがあります。Codespaces の画面にフォルダごとドラッグすると確実です
2. 「Actions」タブ →「補助金情報を巡回」→「Run workflow」で1回動かす
3. 緑のチェックになったら、公開ページを開いて確かめる（URLの最後に `?v=10` などを付けると最新を確認できます）

1回目は、Jグランツと新しく足した市のページのものは「新着」になりません。2回目の巡回から、新しく見つかったものに「新着」が付きます。

## はじめて作るとき

1. 新しいリポジトリを作り（Public）、zip の中身をすべてアップロードする
2. 「Settings」→「Pages」で、Branch を `main`、フォルダを `/(root)` にして「Save」
3. 「Settings」→「Actions」→「General」の一番下「Workflow permissions」を「Read and write permissions」にして「Save」
4. 「Actions」タブ →「補助金情報を巡回」→「Run workflow」を押して、1回目を動かす（データはここで作られます）

## 手で巡回する（Codespaces）

```bash
git pull                              # 自動巡回の結果を先に取り込む
python3 scripts/crawl.py              # いつもの巡回（5〜10分）
python3 scripts/crawl.py --no-details # 一覧ページだけ読む（1〜2分）
git add .
git commit -m "補助金情報を更新"
git push
```

## 巡回しているところ

| 種類 | 巡回先 |
| --- | --- |
| 市のページ | 市が交付する補助金／雇用・就業／企業・商工事業者支援／移住・定住／子育て：助成／子育て支援・保育／高齢・介護福祉／農業：六次産業化 |
| 商工会議所 | 各種補助金／講演会・検定・行事（セミナー・相談会） |
| Jグランツ | 国の補助金API。受付中で、対象地域が「鹿児島県」か「全国」のもの |

`sources.json` に足せば、巡回先を増やせます。`type` が `list` はホームページの一覧ページ、`jgrants` はJグランツ、`events` はセミナー・相談会です。
形がわからないときは、Claude Code に「このURLのページから補助金のリンクを拾えるように sources.json に追加して」と頼みます。

## 自動で読み取っているもの

| 項目 | 読み取り方 |
| --- | --- |
| 受付状況 | 見出しの【募集中】【受付終了】など。締切を過ぎていたら「受付終了」（見出しが募集中のままなら「要確認」） |
| 締切 | 「受付期間」「申請期限」「締切」などに続く日付、または「○月○日まで」。令和の日付は西暦に直す |
| 金額・補助率 | 「上限」「限度額」「補助金額」などに続く金額、「2分の1」「50%」など |
| だれ向け・分野 | 見出しの言葉から判断（`crawl.py` の `TARGET_RULES`、`CATEGORY_RULES`） |
| 新着 | 初めて見つけてから30日以内のもの |
| 確認日 | そのページを最後に読みに行った日 |

読み取りは機械的なので、まちがうことがあります。ページにも「申し込む前に必ずリンク先で確かめてください」と表示しています。

## 異常の知らせ（Issue）

巡回先が読めなかったときや、件数が前回の半分より少なくなったときは、リポジトリの「Issues」に「巡回の確認が必要です」が作られます（すでにあればコメントが足されます）。
GitHub の通知設定によって、メールでも届きます。確認して直したら、Issue を「Close」します。

一時的に読めなかった巡回先は、前回の結果を表示し続けるので、一覧が空になることはありません。

## 相手のサイトへの配慮

- robots.txt で禁止されているページは開きません
- 1ページ開くごとに2.5秒あけ、1回の巡回で開くページは最大200件です
- 巡回は週1回にしています。回数を増やしすぎないようにしてください

## うまくいかないとき

| 症状 | 対処 |
| --- | --- |
| Actions が赤い×になる | 「Workflow permissions」が「Read and write」になっているか確認する |
| Jグランツが「読み込めませんでした」になる | 一時的な不調のことが多い。続くときは Issue の内容を Claude Code に見せて相談する |
| 件数が急に減った | ページのつくりが変わった可能性。Claude Code に巡回の記録を見せて相談する |
| 手で push したら rejected | `git pull --no-rebase --no-edit` してから、もう一度 push |
| 自動巡回が止まった | 60日間変更がないと止まることがある。「Actions」タブで「Enable workflow」を押す |
| 「データを読み込めませんでした」 | 「Run workflow」をまだ動かしていないか、ファイルをダブルクリックで開いている |
